# upm
An ultimate package manager for kindle

## Included mods
- `vnc` — launch a VNC server on the Kindle and connect from a desktop viewer using port 5900.
- `upm` itself — generic package manager commands for installing, removing, listing, updating, searching, and launching mods.

## Example
```
/mnt/us/upm/bin/upm search vnc
/mnt/us/upm/bin/upm launch vnc
```
